# Classic Wave



## 📋 프로젝트 소개

**Classic Wave**는 **고전문학의 그림책과 퀴즈를 제공하는 프로젝트**입니다. 
생성형 AI를 활용해 그림책을 제공하여 사용자가 고전문학을 더욱 흥미롭게 읽을 수 있도록 합니다.
또한, 퀴즈를 자동 생성하여 즐겁고 효과적인 학습을 지원합니다.

- **개발 기간**: 2024.07 (2주)

## ✨ 주요 기능

### 1️⃣ 고전문학 그림책
- 고전문학의 줄거리를 통해 약 10장 분량의 그림책으로 제공
- StableDiffusion3 모델을 사용하여 그림 생성
- GPT4 모델을 사용하여 축약된 줄거리 제공

### 2️⃣ 퀴즈
- 고전문학의 줄거리를 기반으로 5지선다의 퀴즈 생성
- 퀴즈의 정답과 맞춤형 오답 해설

### 3️⃣ 학습 관리 시스템
- 사용자 학습 이력 및 진행 상황 추적
